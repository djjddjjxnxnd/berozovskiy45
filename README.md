# Неизвестный Берёзовский

Локальный школьный путеводитель: каталог из 32 мест, карта, история, три прогулочных маршрута, чат-гид.

## Запуск

Откройте «ЗАПУСТИТЬ САЙТ.bat» или выполните в папке проекта:

```sh
npm run dev
```

Адрес, выбранный сервером, появится в терминале. Обычно это http://localhost:5173.

## Сборка и проверка

```sh
npm run build
npm run lint
```

Готовая сборка находится в dist. Для размещения на хостинге с BrowserRouter настройте перенаправление неизвестных адресов на index.html.

## Что где менять

- src/data/monuments.js — описания всех 32 мест, фотографии и короткие заголовки карточек.
- src/data/routes.js — остановки прогулочных маршрутов.
- src/index.css — палитра, сетки и адаптивное оформление всех страниц.
- src/components/PhotoCarousel.jsx — галереи, автопрокрутка, жесты и полный экран.
- src/components/ChatWidget.jsx и src/utils/chatBrain.js — чат-гид в левом нижнем углу: быстрые ответы, подсказки мест, пароль проекта.
- src/components/ProjectNotice.jsx — табличка «сайт сделан для задания по проекту» при первом заходе.
- scripts/make-placeholders.mjs — генератор SVG-иллюстраций для объектов без фотографий (запуск: node scripts/make-placeholders.mjs).
- public/images — локальные фотографии; для объектов без фото используются фирменные SVG-иллюстрации проекта.

## Карты Яндекс

Все карты сайта (большая карта, мини-карты объектов и схемы маршрутов) работают на JavaScript API Яндекс.Карт 2.1. Ключ не требуется при запуске на localhost (школьный демонстрационный режим). Если сайт выкладывается в интернет, получите бесплатный ключ на developer.tech.yandex.ru и впишите его в константу YANDEX_MAPS_API_KEY в начале файла src/utils/ymapsApi.js. Для загрузки карты нужен интернет.

## Чат-гид и пароль проекта

В левом нижнем углу — иконка чата. Гид подсказывает, куда сходить, что посмотреть с детьми, отвечает на вопросы о любом месте каталога. При вводе пароля проекта (известен только создателю) бот называет имя автора. Логика ответов — локальная, без интернета и внешних сервисов.

Геопозиция запрашивается только по кнопке посетителя. Форма рассказа сохраняет черновик локально в браузере и позволяет скачать его файлом. Серверной отправки и базы заявок в проекте нет.
